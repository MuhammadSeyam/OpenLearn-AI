# OpenLearn AI

OpenLearn AI is an open-source platform for AI-assisted learning. The project aims to provide a modular and self-hostable learning system that combines modern web technologies with AI to deliver personalized educational experiences.

> **Project Status:** Under active development. The project is currently in **Phase 0 (Foundation)**, and the architecture is being built. Features and documentation will be added incrementally as development progresses.

## Tech Stack

- Frontend: Next.js
- Backend: FastAPI
- Database: PostgreSQL
- Cache: Redis
- Containerization: Docker

## Repository Structure

```text
backend/    FastAPI application
frontend/   Next.js application
infra/      Docker and infrastructure configuration
docs/       Project documentation
scripts/    Development and utility scripts
```
