# Research

Supporting research for OpenLearn AI. **Research documents inform decisions;
they are not implementation authority.** Binding decisions live in
[`docs/adr/`](../adr/); product/technical requirements in the
[Technical Specification](../design/OpenLearn_AI_v4_Technical_Specification.md).

## Raw research (non-authoritative)

[`raw/`](raw/) holds unprocessed research input (AI-assisted reports, link
dumps, transcripts) retained for historical reference. Treat as raw material,
not as engineering documentation.
