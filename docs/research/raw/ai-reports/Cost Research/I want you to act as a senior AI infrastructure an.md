### 1. Cloud Providers (General Compute + Storage)

#### GitHub Student Developer Pack

- **Organization:** GitHub Education
- **Website:** https://education.github.com/pack
- **Country:** Global
- **Eligibility:** Verified students (13+), accredited institutions. Undergraduates ✅. Egypt ✅. Open‑source projects ✅ (as a student). Graduation projects ✅.
- **GPU:** No dedicated GPU, but Codespaces can run CPU workloads.
- **Credits:** \$200 DigitalOcean (1 year), \$100 Azure (12 months), plus many partner perks.[^3][^4][^5][^1][^2]
- **API credits:** GitHub Copilot Pro free while verified; some partner API trials.
- **Duration:** While student status is verified (typically 1–4 years, renewable per verification).
- **Difficulty:** Easy–Medium (verification can be strict).
- **Acceptance rate:** High for clearly eligible students.
- **Renewal:** Yes, re‑verify each year.
- **Deadline:** Rolling.
- **Documents:** Student ID / enrollment letter / .edu email.
- **Apply:** https://education.github.com/pack


#### Azure for Students

- **Organization:** Microsoft
- **Website:** https://azure.microsoft.com/free/students
- **Country:** Global, but **Egypt has access issues** for the \$100 credit via self‑service; some students report needing institutional verification or alternative paths.[^72]
- **Eligibility:** 18+, full‑time students at accredited institutions. Undergraduates ✅. Egypt: technically eligible but sometimes blocked in practice. Open‑source/graduation projects ✅.
- **GPU:** Access to GPU VMs but must pay beyond free services; credits can be used for GPU VMs.
- **Credits:** \$100 for 12 months + select free services.[^4][^73][^74][^2]
- **Duration:** 12 months.
- **Difficulty:** Easy (if country is supported).
- **Renewal:** No (one per student).
- **Deadline:** Rolling.
- **Documents:** Academic email / student verification.
- **Apply:** Via GitHub Pack or direct portal.

> If Azure for Students is blocked for your Egyptian account, you can still get Azure credits via **Microsoft Founders Hub** (below) once you register a startup entity.

#### Google Cloud for Students / Education

- **Organization:** Google Cloud
- **Website:** https://cloud.google.com/edu/students

- **Credits:** Typically skill badges and small credits via Skills Boost; not a large general‑purpose grant for undergrads.[^75]
- **GPU:** TPUs/GPUs via Research Credits (PhD/faculty only).
- **Duration:** Varies by campaign.
- **Difficulty:** Easy for skill credits; Hard for research credits.
- **Apply:** Via Google Cloud Education pages.


#### AWS Activate (Founders \& Portfolio)

- **Organization:** AWS
- **Website:** https://aws.amazon.com/activate
- **Country:** Global.

- **Credits:** Founders: \$1K; Portfolio (via partners): up to \$100K.[^21][^22][^23][^24][^20]

- **Difficulty:** Medium (Founders), Hard (Portfolio).
- **Renewal:** Generally one package per tier; can stack via different programs/partners.
- **Deadline:** Rolling.
- **Documents:** Company website, incorporation info, AWS account, description of product.
- **Apply:** https://aws.amazon.com/activate → “Apply for Activate Founders”.

## Estimated MVP API Costs (Light / Medium / Heavy)

- **OCR:** 100–1,000 pages/month (student uploads).
- **LLM calls:**
    - Light: 50 users, ~20 queries/day each → ~1K queries/day.
    - Medium: 200 users, ~30 queries/day → ~6K queries/day.
    - Heavy: 1,000 users, ~40 queries/day → ~40K queries/day.
- **Embeddings:** 1 chunk per page; 100–1,000 pages/month.
- **Speech (optional):** 10–100 hours/month.

Using approximate pricing (as of 2026; verify current rates):

- LLM (mid‑size open model via Together/Fireworks): ~\$0.20–\$0.50 per 1M tokens.
- Embeddings (Jina/Voyage/etc.): ~\$0.01–\$0.10 per 1M tokens.
- OCR (Google/Azure): ~\$1–\$3 per 1,000 pages.
- Speech: ~\$0.02–\$0.10 per minute.

    - LLM: \$5–\$20

    - LLM: \$30–\$150
