# Risk Register v1 - OpenLearn-AI (Pod D)

This document tracks the identified risks, impact scores, likelihoods, mitigation strategies, triggers, and statuses for Pod D scope (CI, Staging, LiteLLM, and Release Readiness).

## Top 3 Priority 1 (P1) Risks

1. **REC-01: CI & Eval Harness Integration Failure** (Score: 25) - High impact on delivery and PR workflows.
2. **REC-02: Staging Outage & LiteLLM Proxy Failure** (Score: 20) - High impact on staging smoke tests and demo readiness.
3. **REC-03: API Key Leakage or Rotation Failure** (Score: 20) - Critical security risk affecting external providers and uptime.
