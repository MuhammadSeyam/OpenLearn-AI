الفكرة الأساسية

Backpropagation هي خوارزمية لحساب تدرّجات (gradients) دالة الخسارة بالنسبة لكل وزن في الشبكة، باستخدام قاعدة السلسلة (Chain Rule).

الخطوات

  1. Forward Pass: نمرر المدخلات عبر الشبكة ونحسب المخرجات
  2. حساب الخسارة: نقارن المخرجات بالقيم الحقيقية
  3. Backward Pass: نحسب المشتقات من الخرج إلى الدخل
  4. تحديث الأوزان: نستخدم Gradient Descent

المعادلة الأساسية

# Chain rule for layer l
delta = dL/dz * dz/da * da/dW

# Simplified form
delta[l] = (W[l+1].T @ delta[l+1]) * sigmoid_prime(z[l])
