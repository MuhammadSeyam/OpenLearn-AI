# Ground Truth (`data/ground_truth/`)

**Status: intentionally empty.** No ground truth exists yet and none was
fabricated. Hand-verified transcription is a separate, dedicated task — sloppy
or auto-generated ground truth silently caps the validity of every metric
computed against it (handbook Phase 4).

Planned layout once annotation starts (per handbook Phase 4):

```
custom/<doc_id>/
├── page_001.txt            # plain-text transcription, reading order
├── page_001.md             # Markdown transcription (headings, lists)
├── tables/page_001_t1.html # HTML ground truth for table regions (TEDS)
└── meta.json               # annotator, dates, review status, conventions used
```

Rules that will apply:

- Ground truth is **hand-verified**; never generated by an engine under
  evaluation (circularity).
- Corrections to ground truth are explicit commits with a changelog entry —
  they retroactively affect all prior benchmark results.
- An annotation guideline (diacritics policy, formula/figure marking,
  mixed-language spans) will be written before the first page is transcribed.
